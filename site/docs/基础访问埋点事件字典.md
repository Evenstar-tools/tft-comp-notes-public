# 基础访问埋点事件字典与接入说明（首期 · 腾讯云 RUM）

本站点首期基础访问统计接入 **腾讯云前端性能监控 RUM（广州，`aegis-web-sdk`）**，仅在显式配置环境变量且命中正式域名白名单时启用，默认关闭。

## 1. 环境变量与停报控制

所有开关均通过公开运行时环境变量控制，不在仓库硬编码任何应用 ID 或私密配置：

| 变量名 | 必填 | 说明 |
| --- | --- | --- |
| `NEXT_PUBLIC_RUM_ENABLED` | 是 | 设为 `1` 或 `true` 启用；留空或设为 `0` 即全局停报 |
| `NEXT_PUBLIC_RUM_APP_ID` | 是 | 腾讯云 RUM 对应应用的公开上报 ID（测试环境与正式环境使用独立应用） |
| `NEXT_PUBLIC_RUM_ALLOWED_HOSTS` | 是 | 允许采集的正式域名白名单，逗号分隔（如 `tftnotes.com,www.tftnotes.com`）；不配时默认不采集任何域名 |
| `NEXT_PUBLIC_RUM_HOST_URL` | 否 | 上报域名，默认 `https://rumt-zh.com`（广州区） |
| `NEXT_PUBLIC_RUM_ENV` | 否 | RUM 环境标记，默认 `production`（测试应用可设为 `test`） |

**快速停报 / 隔离方式：**
- **紧急全站停报**：在 EdgeOne Pages 环境变量中将 `NEXT_PUBLIC_RUM_ENABLED` 改为 `0`（或清空 `NEXT_PUBLIC_RUM_APP_ID`）并触发重新部署即可只停云顶笔记采集，不影响同账号其他应用。
- **单会话/站主自测免采集**：访问任意页面附带 `?rum_ignore=1`（写入 `sessionStorage.tft_rum_ignore = "1"`，该标签页全程不上报；可用 `?rum_ignore=0` 恢复），或在浏览器 `localStorage` 设置 `tft_rum_ignore = "1"` 长期免采。
- **自动排除路径**：`/manage`、`/editor/owner`、`/api/*`、`/search`、`/find` 均不加载 SDK、不上报任何事件。

## 2. SDK 采集边界与隐私脱敏

- **单口径手动上报**：初始化 `aegis-web-sdk` 时显式关闭自动 PV（`pvUrl: ""`、`spa: false`）、错误监控、页面性能、Web Vitals、接口/静态资源测速、白名单与限流探针请求，并通过 `beforeRequest` + `onBeforeRequest` 双重拦截，**仅放行以下 5 个白名单自定义事件**，同时保留 `aid` 匿名设备标识用于同浏览器去重。
- **URL 与字段脱敏**：`urlHandler` 与 `originFrom` 统一改写为规范公开路径（剥离所有搜索词、筛选参数、活动参数与 hash）；自定义字段严格落入白名单枚举或公开 ID，绝不上报原始搜索框输入、完整 Referrer、口令、账号、站主草稿或私人棋盘内容。
- **失败静默降级**：SDK 按需动态加载并全程隔离异常，网络阻断或脚本异常不影响阅读、搜索、编辑和导图。

## 3. 首期 5 个白名单事件字典

所有自定义属性均使用 `ext1` / `ext2` / `ext3`（免控制台配置 `ext4–ext10` 枚举表）：

| 事件名 | `ext1` | `ext2` | `ext3` | 触发与去重口径 |
| --- | --- | --- | --- | --- |
| `page_view` | 页面类别：`home` / `guide` / `heroes` / `items` / `traits` / `augments` / `combos` / `editor` / `updates` | 规范页面键：`home:recommended` / `home:all_guides` / `home:hero_augments` / `home:comp_trends` / `guide:<publicId>` / `heroes:list` / `heroes:grid` / `heroes:stats` / `items` / `emblems` / `traits` / `traits:medley` / `augments` / `combos` / `editor` / `updates` | 入口渠道：落地页白名单活动标签（`bilibili` / `wechat` / `xiaohongshu` / `douyin` / `nga` / `tieba` / `qq` / `weibo` / `feishu` / `github` / `datatft` / `metatft`）→ Referrer 域名分类（上述社区 / `search_engine` / `external`）→ `direct`；站内导航记 `internal` | 公开页首开、刷新、真实页面或一级主栏目切换、前进后退返回不同规范页面各记 1 次。预加载、重渲染、搜索弹层开关、普通筛选与排序切换不重复计入。 |
| `guide_view` | 公开攻略 ID（如 `sample-block-0001`） | 阅读方式：`detail`（攻略详情页）/ `quick_view`（首页列表快看棋盘） | 入口：`home_rec` / `guide_list` / `site_search` / `direct` / `other` | 详情页内容成功渲染记 1 次（同页切阶段/变阵/筛选不重计）；主动展开并成功显示「快看棋盘」记 1 次（收起后重新展开才算新一次）。 |
| `search_results` | 结果状态：`has_results` / `no_results` | 搜索入口：`overlay`（顶栏搜索弹层）/ `home_inline`（首页内联搜索框） | 空字符串 `""` | 非空输入稳定展示当前输入对应的有效结果时记 1 次。严格排除 IME 输入法组字、取消/过期请求、接口错误与历史返回恢复结果。**绝不上报搜索词**。 |
| `search_result_open` | 结果类型：`guide` / `unit` / `item` / `trait` / `augment` / `other` | 结果位置分组：`1` / `2-3` / `4-10` / `11+` | 搜索入口：`overlay` / `home_inline` | 鼠标、触屏或键盘（含回车激活主结果）打开任意搜索结果时记 1 次。 |
| `tool_action` | 操作类型：`combo_first_result` / `poster_open` / `poster_download` / `poster_open_original` / `poster_share` / `poster_copy_link` / `editor_import_guide` / `editor_import_combo` / `editor_export_image` / `editor_copy_text` / `editor_save_local` | 公开攻略 ID（关联攻略时附带，否则为空） | 工具场景：`combos` / `poster` / `guide` / `editor` | 凑羁绊用户主动修改手牌/条件并展示可用结果时同页首次记 1 次；一图流下载/原图/分享仅在图片已生成且用户点击时触发；编辑器内部动作仅游客模式记录，排除站主工作区。 |

## 4. 首期报表取数口径

- **访问量与设备数**：浏览次数取 `page_view` 事件总数；访问设备按同一时间窗内 RUM 匿名设备标识（`aid`）整段去重（北京时间日/周/月分别整段去重）；入口渠道分布仅统计 `entry_channel != internal` 的落地页事件。
- **热门攻略与资料页**：资料页按 `page_view` 的 `ext2` 汇总；攻略按 `guide_view` 的 `ext1` 分别统计 `detail` 与 `quick_view` 的次数及去重设备数。
- **搜索效果**：零结果率 = `search_results(no_results)` ÷ (`has_results + no_results`)，可按 `ext2`（`overlay` / `home_inline`）拆看；结果点击看 `search_result_open` 的类型与位置分组分布。
- **工具使用**：按 `tool_action` 的 `ext1` 看各工具终态动作次数与去重设备数；全站核心操作设备占比取选定动作设备并集后与当期访问设备求交集。
- **数据留存提醒**：腾讯云 RUM 原始事件日志官方保留期为 30 天，月活及长期趋势需按周期导出并留存聚合快照。
